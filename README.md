# Volve Survival: время до обводнения скважины

Третий проект трилогии по данным месторождения **Volve** (Equinor, Северное
море). Задача — оценить время от запуска добывающей скважины до обводнения
(30-дневное скользящее WC > 50 %) методами анализа выживаемости.

## Почему survival-анализ

Месторождение остановлено в 2016 году решением оператора (демонтаж платформы),
а не по состоянию скважин: скважины, не обводнившиеся к концу наблюдения, —
это **цензурированные** наблюдения. Игнорирование цензурирования занижает
время до обводнения. Survival-анализ учитывает их корректно.

## Что внутри

- **Определение события**: 30-дневное скользящее среднее WC > 50 % — окно
  отсекает разовые технологические прорывы; когорта — скважины со «сухим
  стартом» (WC ниже порога в первый месяц), как требует метод. Всё, что не
  попало в когорту, попадает в таблицу с причиной — отбор не молчаливый.
- **Каплан–Мейер, реализованный руками** (без lifelines): кривая выживаемости,
  медиана, группировка по расстоянию до ближайшей нагнетательной скважины.
- **Log-rank тест** — тоже собственная реализация: близость к ППД даёт
  ожидаемое направление, но p = 0.36 при n = 6 — иллюстрация метода,
  не доказательство.
- **Чувствительность к порогу** (10–90 %): с ростом порога цензурированных
  становится больше, медиана растёт — порог надо фиксировать до анализа.
- **Граница применимости Кокса**: на шести наблюдениях максимум
  правдоподобия уходит на границу параметра (сепарация), то есть **оценка β
  не идентифицируется**. Это показано явно — ограничением поиска и бутстрепом,
  а не подменено красивым p-value.

## Ключевые результаты

- Событие у 5 из 6 скважин когорты; **медианное время до обводнения — 23 мес**
  с запуска (Каплан–Мейер, 23.2).
- 1 скважина цензурирована закрытием поля — без учёта цензурирования оценка
  была бы смещена вниз.
- Порог меняет вывод: медиана **13 мес** при 10 % и **61 мес** при 90 %.
  Последняя точка опирается на два события, поэтому в один ряд с остальными
  не ставится — в таблице она помечена.

| Порог WC | Событий | Цензурировано | Медиана, мес |
|---|---|---|---|
| 10 % | 5 | 0 | 13.0 |
| 30 % | 5 | 0 | 18.1 |
| 50 % | 5 | 1 | 23.2 |
| 70 % | 4 | 2 | 33.5 |
| 90 % | 2 | 4 | 61.4 * |

\* мало событий — медиана неустойчива.

## Структура и запуск

```
├── survival.py            # ядро: когорта, Каплан–Мейер, log-rank, Кокс
├── analysis.py            # исходник ноутбука в формате jupytext-ячеек (# %%)
├── volve_survival.ipynb   # собранный и исполненный ноутбук
├── make_notebook.py       # сборка analysis.py -> ipynb
├── tests/test_survival.py # числа проверяются из данных
├── data/daily.csv         # суточная добыча Volve
├── data/locations.csv     # координаты скважин
└── requirements.txt       # версии зафиксированы
```

```bash
pip install -r requirements.txt
pytest -q                                    # проверка чисел
python make_notebook.py                      # сборка ноутбука
jupyter nbconvert --to notebook --execute --inplace volve_survival.ipynb
```

## Чем проверено

`tests/test_survival.py` пересчитывает из `data/daily.csv` всё, что заявлено
в этом README:

- состав когорты — 6 скважин, 5 событий, 1 цензурирована;
- медиана Каплана–Мейера — 23.2 мес;
- log-rank — χ² = 0.83, p = 0.364, наблюдаемых 2 против ожидаемых 1.2;
- таблица чувствительности — все пять порогов, включая 61.4 мес при 90 %;
- свойства кривой выживаемости — S(0) = 1, кривая не возрастает, медиана
  не определена, если S не опускается до 0.5;
- в README нет старых ошибок: занижённая верхняя граница чувствительности и
  выданный за результат коэффициент Кокса были артефактами и пересчитаны.

CI прогоняет эти тесты на каждый push (`.github/workflows/tests.yml`).

## Трилогия Volve

1. [Volve EDA](https://github.com/Alex91132/volve-eda) — качество данных, гипотезы, decline;
2. [Volve ML](https://github.com/Alex91132/volve-ml-forecast) — прогноз дебита на месяц вперёд;
3. этот репозиторий — survival-анализ времени до обводнения.
